选择正确的评价指标：从Accuracy、ROC到PR-F1

博主原创文章，转载请说明出处，但是不说我也管不了你🏳️

前言

机器学习的分类任务中，模型评估可以说是一个最重要的环节，因为这直接关系到你训练出来的模型能不能用或者好不好用，其涉及的相关评估指标也是比较繁多。在学习这些知识的途中，我也是产生了成吨的疑问，遂留下此笔记。本文主要讲解几个经典的评估指标：

  • Accuracy：正确率，即预测正确的样本占总样本的比例
  • ROC-AUC：Receiver Operating Characteristic Curve，简称ROC曲线，一般和AUC结合用于描述模型对正负样本的排序能力
  • PR-F1：Precision、Recall、F1-score表示查准率、查全率与两者的调和平均结果，这个三个指标目前仍然是十分常用的指标

本文将对各指标的含义进行深入理解，详细阐述各指标更关注模型的哪些能力，同时讨论梳理以上指标在各种场景下的有效性与局限性。为方便理解，本文只用二分类任务举例子。

本文适合机器学习初学者(只需具备基本的数学知识)，阅读完此文章后，读者应能充分理解以上指标的含义、适用场景并能够判断指标的好坏体现出了什么结果。

正文

一、混淆矩阵

混淆矩阵(Confusion Matrix)是从对分类结果的总结表示，所谓混淆是指对于模型在分类结果中把谁和谁搞混了，矩阵就是用矩阵形式把这个混淆的结果用矩阵形式表示出来，它是从模型预测混淆的角度出发来表示结果，混淆矩阵如下图表示：

矩阵中TP、FN、FP、TN是混淆的结果，其中第一个字母表示预测对没对，第二个字母表示预测对哪了或者错哪了，如下：

  • TP（True Positive，真正例）：预测正确且预测为正例的样本。即该数据的真实值为正例，预测值也为正例的情况；
  • TN（True Negative，真负例）：预测正确且预测为负例的样本。即该数据的真实值为反例，预测值也为反例的情况;
  • FP（False Positive，假正例）：预测错误且预测为正例的样本。即该数据的真实值为反例，但被错误预测成了正例的情况；
  • FN（False Negative，假负例）：预测错误且预测为负例的样本。即该数据的真实值为正例，但被错误预测成了反例的情况。

注意理解什么是正例样本，什么是负例样本。这里的正负不代表对错，只表示结果的不同，谁正谁反只取决于实际需求。假设当前有一个二分类任务，任务目标是从众多动物照片中分类狗与不是狗的照片，此时：

  • 正例样本：狗的图片
  • 负例样本：不是狗的图片

当然正例样本也可以是不是狗的图片，其主要取决于实际的分类目标需求。

注意：混淆矩阵中TP也有叫做真阳例的，或者还有其他叫法的，我觉得这种叫法不够直观，所以对于多种叫法的我只选取我看起来最直观的那一种叫法，下文也是相同做法，对于其他叫法我也不做赘述。

二、Accuracy：整体对不对

2.1 概念

在机器学习分类早期，有一个十分朴素且核心的问题：分类对了多少？所以自然而然就引入了Accuracy(正确率)，公式： \[ Accuracy=\frac{TP+TN}{TP+TN+FP+FN} \] 当误分类代价相同、类别较平衡时，此时Accuracy(正确率)已经能够很好的评估模型的分类能力，谁的正确率高，谁的性能就更好。

2.2 总结

当数据类别十分不平衡时，正确率将无法用于评估模型的分类能力，例如：

  • 正样本: 1000
  • 负样本: 10

在置信度阈值为0.5的情况下，假设此时模型A的预测结果为：TP为900，TN为0，FP为10，FN为100，此时正确率\(\frac{900+0}{900+0+10+100}=81.8\%\)，假设此时模型B的预测结果为：TP为890，TN为10，FP为0，FN为110，此时正确率\(\frac{890+10}{890+10+0+110}=81.8\%\)。此时A、B正确率相同，但是A对于负样本的预测全部错误，B对负样本的预测全部正确，直观上看显然A模型优于B模型。更甚的场景，模型对于所有样本一律预测为正样本，正确率还更高了。所以在样本极度不平衡时，正确率已经无法有效地评估模型能力了。

另外，正确率依赖于提前选择一个固定的分类阈值（通常是0.5）。改变阈值，正确率会剧烈变化，由此可能因为一个“运气好”的阈值得到高正确率，但模型实际并不稳定，导致无法有效评价模型之间的能力强弱。

  • 有效性：
    • 当正负样本数量相近且误分类成本相同时，是最好理解、最直接的性能指标，越高就越好。
  • 局限性：
    • 无法应对样本极度不平衡的场景，此时这个评价指标几乎是完全没用。
    • 依赖单一固定阈值，不能反映模型在不同判断标准下的表现。

三、ROC-AUC：对正负样本的排序能力强不强

ROC（Receiver Operating Characteristic Curve，接收者操作特征曲线）最初用于信号处理领域，ROC曲线首先是由二战中的电子工程师和雷达工程师发明的，用来侦测战场上的敌军载具（飞机、船舰），也就是信号检测理论[1]。

3.1 两个核心概念

  • 真正例率 (TPR，True Positive Rate，也叫查全率)：在总的正例样本中，模型正确地抓出了多少正例样本。

    • 公式：\(TPR=\frac{TP}{TP+FN}\)

    • 我们希望这个值越高越好（越大表示模型发现正例的能力越强）。

  • 假正例率 (FPR，False Positive Rate)：在总的负例样本中，模型错误地抓出了多少负例样本。

    • 公式：\(FPR=\frac{FP}{TN+FP}\)
    • 我们希望这个值越低越好（越小表示模型误伤负例的程度越低）。

3.2 ROC曲线的构成与形状

当改变模型判断的“阈值”（比如从非常严格到非常宽松）时，会得到一系列 (FPR, TPR) 的点，将这些点连接起来就形成了ROC曲线。

一条典型的ROC曲线通常从左下角 (0,0) 出发，延伸到右上角 (1,1)：

  • 左下角 (FPR=0, TPR=0)：模型将所有样本都判为负例，没有抓到正例，也没有误伤。
  • 右上角 (FPR=1, TPR=1)：模型将所有样本都判为正例，抓到了所有正例，但也误伤了所有负例。
  • 理想点 (FPR=0, TPR=1)：模型完美地抓住了所有正例，同时没有误伤任何一个负例。ROC曲线越接近这个左上角，模型性能越好。

3.3 AUC：一个数值化的综合指标

AUC (Area Under the Curve) 就是ROC曲线下的面积。实际上，AUC的面积大小等同于同时从正例、负例中分别随机选一个样本，模型将正例排在负例前面的概率值，这体现出了模型对正负样本的排序能力，简单的推导过程可以见AUC指标的概率解释及其推导。

注意理解这里的排在负例前面是什么意思。实际上分类任务中，输出的结果一般都会是一个概率值，例如在预测一张图片是否是狗的分类任务中，同时从正例(狗的图片)与负例(不是狗的图片)中分别随机选取一张图片，假设为图片A与B，模型此时输出：

  • A：0.9
  • B：0.1

我们希望A的概率值总是大于B，因为这样正例与负例总是能被某一个置信度阈值区分开。甚至我们希望所有正负例都能被完美分开，也就是对所有正例输出的预测概率大于所有负例，所有正例都排在负例前面。

可见，实际上ROC也就是AUC这个指标评估的是模型对所有正样本、负样本的排序能力，且主要是将正样本排在前面的能力。

性能判断：

  • AUC = 1：完美分类器（现实中极少见）。
  • AUC > 0.9：非常优秀。
  • 0.8 ≤ AUC < 0.9：良好。
  • 0.7 ≤ AUC < 0.8：有一定价值。
  • AUC = 0.5：无价值（相当于随机猜测，曲线是一条从 (0,0) 到 (1,1) 的对角线）。
  • AUC < 0.5：通常意味着模型学习反了（比随机猜测还差）。

3.4 总结

ROC-AUC天然关注模型的排序能力，会评估模型对正样本与负样本整体的区分能力。但是遇到正负样本极端不平衡时，ROC-AUC会几乎没反应，这对于一些分类任务是不可接受的。比如，在罕见病例筛查中，有病为正例，没病为负例，假设：

  • 有病的正例：10
  • 无病的反例：100000

此时模型预测的结果是将10个正例穿插到了1000个负例中，虽然误报了(FP)了1000个病人，此时\(FPR=\frac{1000}{100000}=0.01\)仍然很小，且总体ROC曲线如下：

AUC值表明这是一个几乎完美的模型（在排序上），但是实际上误报数量已经很多了，此时ROC-AUC对误报敏感的任务无法适用。

  • 有效性：
    • 对样本不平衡不敏感：即使在 1000:1 的数据上，AUC 依然能公正地评估模型区分能力【注意仅仅是区分能力，也就是排序能力】。
    • 综合评估排序能力：AUC 等于“随机正样本排在随机负样本前的概率”，天然适用于排序任务。
    • 不依赖阈值：综合了所有可能阈值下的性能，评估更全面。
  • 局限性：
    • 在极度不平衡时会过度乐观：负样本极多时，FPR（假正例率）分母极大，即使错了不少负样本，FPR 看起来仍然很小，导致 AUC 虚高。
    • 不能单独聚焦在少数类上：它同时考虑正负类，如果你只关心正类（如罕见病），ROC 可能会被海量负类的微小变化干扰（从公式上可以直观理解，本质上是类不平衡问题）。
  • 适用场景：
    • 推荐系统/搜索排序：你需要评估“用户感兴趣的物品是否排在前面”，而不关心具体阈值。
    • 信贷风控模型：需要比较不同模型对“好/坏客户”的排序能力。
    • 负样本也很重要的场景且类别不是极端不平衡

四、PR-F1：不仅要选得全，还要选的准

4.1 Precision(查准率)与Recall(查全率)

Precision(查准率)旨在评估模型预测的所有正样本中，正确率是多少。即模型预测为正的样本中，有多少是真的正样本。其公式如下： \[ Precision=\frac{TP}{TP+FP} \]

recall(查全率)旨在评估模型预测正确的正样本个数占整个正样本个数的比例。即所有真实正样本中，有多少被模型找出来了。其公式如下： \[ Recall=\frac{TP}{TP+FN} \]

4.2 F1 score

对于 Precision 和 Recall ，在实际应用中，一般都会将两者综合来用于评估模型性能。F1 score(F1分数)衡量的就是 Precision 和 Recall 的综合表现，其公式如下： \[ F1=\frac{2}{\frac{1}{Precision}+\frac{1}{Recall}}=\frac{2 \times Precision \times Recall}{Precision+Recall} \] 从公式可以看出，只有 Precision 和 Recall 都比较大时，F1分数才会比较大。

4.3 总结

从公式上可以看出，F1分数实际上更关注模型对于正样本预测情况，查准率与查全率都是针对正样本的数据。但对于负样本数据过少，更不能通过F1分数去评估误判(FPR)的情况。对于负样本误判情况，假设以下任务场景：

  • 有病正例：100,000

  • 没病负例：100

指标项 数量
TP 90,000
FP 100
FN 10,000
TN 0

此时： \[ Precision=\frac{90000}{90000+100}\approx99.89\%\\ Recall=\frac{90000}{90000+10000}=90\% \]

F1≈94.68%，F1 很高，但是： \[ FPR=\frac{100}{100+0}=100\% \] 也就是说：所有负样本都被误判成了正样本，但 F1 仍然很高。原因是正样本太多，FP=100 相对于 TP=90000 来说很小，所以 Precision 仍然很高。

我觉得这实际上也是一种样本不平衡问题，F1尝试解决样本不平衡问题，可惜好像只解决了一半😂。

  • 有效性
    • 对于类别极度不平衡但是更关注正样本的场景，F1十分擅长。实际上就是无所谓样本平不平衡，只要重点关注地是正样本，F1都能很好地胜任
  • 局限性
    • 对负样本整体表现关注较少
  • 适用场景
    • 异常检测、医学筛查、欺诈检测，这些异常样本通常很少但非常重要的场景。

五、总结

指标 主要衡量 优点 局限 适合场景
ACC 整体预测正确率 简单直观 类别不均衡时容易误导 类别均衡、多分类整体评估
ROC-AUC 正负样本排序能力 不依赖固定阈值，适合看区分能力 类别极不均衡时可能过于乐观 风险评分、阈值可调的二分类
PR-F1 正类预测质量 适合少数类、关键类、不均衡任务 主要关注正类，依赖阈值 异常检测、欺诈检测、疾病筛查

总的来说：

  • 类别均衡，看 ACC
  • 需要看模型区分能力，看 ROC-AUC
  • 类别不均衡且正类重要，看 PR-F1
